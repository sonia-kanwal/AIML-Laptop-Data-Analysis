# AIML Laptop Data Analysis

## Project Overview
This project analyzes a laptop dataset using Python to understand laptop prices, companies, laptop types, hardware specifications, and relationships between different features.

## Objective
- Explore and understand the laptop dataset.
- Clean and prepare the data.
- Perform exploratory and statistical analysis.
- Visualize important patterns and relationships.
- Identify major findings and key insights.

## Dataset
- **Dataset:** Laptop Price Dataset
- **Source:** Kaggle
- **Records:** 1,303
- **Relevant Features:** 11 after removing the unnecessary `Unnamed: 0` column.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab
- Jupyter Notebook

## Workflow
1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis
4. Data Visualization
5. Statistical Analysis
6. Findings and Insights

## Visualizations
The project includes visualizations such as:
- Company distribution
- Laptop type distribution
- Price distribution
- Correlation heatmap
- Box plot
- Scatter plot
- Line chart
- Count plot
- Pair plot
- Violin plot
- Pie chart

## Statistical Analysis
Statistical measures including mean, median, standard deviation, minimum price, and maximum price were calculated to understand the distribution of laptop prices.

## How to Run
1. Download or clone this repository.
2. Open the `.ipynb` file in Google Colab or Jupyter Notebook.
3. Upload/use the provided dataset.
4. Run the notebook cells in order.
